# Edit my video

The person opened KiroCut, the video editor inside this Kiro workspace.

1. Read `plugins/kirocut/skills/start/SKILL.md` and follow it.
2. If a tool is missing, run the setup skill before the cut.
3. If they pasted reference videos, measure that style and edit their footage in it. If they did not, use the style they pick in the window.
4. They approve the cut, then the look, then the render.
5. Do not ask them to paste an API key into the chat.
