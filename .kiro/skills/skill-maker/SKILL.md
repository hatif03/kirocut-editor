name: skill-maker
description: Helps the user make their own Kiro skill for editing videos, step by step. Interviews them briefly (what the skill does, an example video, what good looks like), runs the task once without a skill to see what goes wrong, writes three test scenarios, drafts the SKILL.md to the skill-authoring guide (clear name, a description that says what and when, a checklist, a check-and-fix loop, one example), saves it to their skills folder, tests it against the scenarios in a fresh agent, and improves it with them. Skills made here plug into KiroCut (the edit folder, the review page, the safe zone) and can run as a style. Use when the user says 'make a skill', 'create a skill', 'turn this into a skill', 'help me write a skill' or 'build my own editing skill'. Not for adding rules to a skill that exists from a video's notes (skill-improver), and not for copying a creator's style from their videos (style-match).

# skill-maker

Kiro loaded this copy so the skill is available in this folder. Read and follow `plugins/kirocut/skills/skill-maker/SKILL.md` in full before doing anything else.

In that file, `${KIROCUT_SKILL}` means `plugins/kirocut/skills/skill-maker` and `${KIROCUT_PLUGIN}` means `plugins/kirocut`. Those paths start at the root of this repo. They are not the folder this file is in.
