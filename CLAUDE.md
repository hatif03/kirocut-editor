# KiroCut

This folder edits video inside Kiro. When someone says "edit my video", drops a video, or pastes a link, read `plugins/kirocut/skills/start/SKILL.md` and follow it.

If that skill did not load, ask whether to install `plugins/kirocut` and then `plugins/style-match`. After installing, they should start a new chat.

If the task is to change this repo, follow `AGENTS.md` instead.
