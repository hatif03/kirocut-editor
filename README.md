# KiroCut

Open this folder in Kiro and say "edit my video".

It cuts retakes, false starts and pauses out of a talking-head take, then styles the cut with captions, zooms and cards. A long video can be turned into clips. A website can be turned into a product film.

`plugins/kirocut` does the edit. `plugins/style-match` measures a style from reference videos you choose. This repo does not ship links to other people's accounts.

Footage you make here stays out of git.
